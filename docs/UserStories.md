# User Stories

## Member Stories
- As a Member, I want to log in securely so that my personal schedule data is protected.
- As a Member, I want to view my upcoming assigned task so I know what my responsibility is for the week.
- As a Member, I want to see the specific Monday date of my assigned task.
- As a Member, I want to view the full upcoming cleaning schedule to see who is assigned to other tasks.
- As a Member, I want to view the status of my tasks to see if they have been marked as completed.
- As a Member, I want to view my past task history to keep track of my completed responsibilities.
- As a Member, I want to receive email reminders 3 days before, 1 day before, and on the day of my task so I don't forget my duty.
- As a Member, I want to mark my assigned task as "Completed" so an Admin can verify it.

## Admin Stories
- As an Admin, I want to create a weekly schedule consisting of three specific tasks.
- As an Admin, I want to assign three different members to the three tasks for a given week.
- As an Admin, I want to verify a task marked as completed by a member to ensure it was done properly.
- As an Admin, I want to mark a task as VERIFIED to complete the workflow.
- As an Admin, I want to modify assignments if a member is unavailable or a mistake was made.
- As an Admin, I want to view a list of all members.
- As an Admin, I want to monitor pending and completed tasks across all users.
- As an Admin, I want to manually trigger or send reminders to specific members.
- As an Admin, I want to manage user accounts (create, edit, disable).
